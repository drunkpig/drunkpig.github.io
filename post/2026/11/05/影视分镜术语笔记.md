## 一句话定义

**分镜（storyboard / 分镜头）= 把文字剧本拆成一个个「镜头」，并写清每个镜头怎么拍、拍多久、画面里有什么的施工图。**

编剧写的是「故事怎么发生」，分镜写的是「观众依次看到什么」。

## 分镜的三种形态

| 形态 | 专业叫法 | 产出 | 用途 |
|---|---|---|---|
| 文字分镜 | 分镜头脚本 / 镜头表 / shot list | 表格 | 导演、摄影、美术、剪辑的执行依据 |
| 画面分镜 | 故事板 storyboard | 按镜号排列的关键帧图 | 定构图、机位、景别、光影 |
| 动态分镜 | animatic / 动态故事板 | 加时间轴和音轨的预演视频 | 定节奏、时长、转场 |

动画行业里分镜的地位更核心。日本动画叫 **絵コンテ（e-konte）**，它同时承担时间轴、台词、作画指示的功能，相当于整部片子的总设计图。

## 标准分镜表包含哪些列

| 列 | 内容 | 例 |
|---|---|---|
| 镜号 | 全片唯一编号 | 12 |
| 景别 | 远景 / 全景 / 中景 / 近景 / 特写 | 近景 |
| 角度 | 平视 / 俯视 / 仰视 / 越肩 | 45° 俯视 |
| 运镜 | 固定 / 推 / 拉 / 摇 / 移 / 跟 / 手持 | 缓慢推近 |
| 时长 | 秒 | 3s |
| 画面内容 | 构图、人物动作、环境、光影 | 把文件拍在桌上 |
| 台词 / 音效 / 音乐 | 对白、拟音、BGM 进出点 | 「数字一分不少。」 |
| 转场 | 切 / 叠化 / 划像 / 黑场 | 硬切 |
| 备注 | 特效、道具、演员、风险点 | 合同文字需清晰 |

一条基本原则：**一个镜头只承担一个叙事任务**。镜头里塞两个信息点，观众通常两个都记不住。

## 场、镜头、分镜的层级

这个层级最容易被说反，先给结论：

```text
剧本 → 剧集(series) → 集(episode) → 场(scene) → 镜头(shot) ≡ 一个分镜条目 → 帧(frame)
                                    ↑
                              场景(set) 是美术资产，可跨多场复用
```

- **场包含多个镜头**：同一时间、同一地点的一段连续动作。
- **一个镜头 = 一个分镜**：二者是同一层的 1:1 关系，不存在「一个镜头包含多个分镜」。

「分镜」这个词有三个用法，混用是误解的根源：

| 用法 | 指什么 | 单位 |
|---|---|---|
| 动词 | 「做分镜」这道工序 | — |
| 文档 | 分镜脚本 / 故事板 / 分镜本 | 一整本 |
| 条目 | 分镜表里的一行 | 一行 = 一个镜头 |

所以业内说「第 12 个分镜」，意思就是「第 12 个镜头」。

### 为什么容易觉得「镜头里还有分镜」

有三种情况确实会让一个镜头出现多张图，但它们都不叫「多个分镜」：

1. **长镜头 / 运动镜头**：一个镜头内的推、拉、摇、移，会用多张关键帧示意。这是同一镜头的多个时间点，不是多个镜头。
2. **多机位**：一个动作由 A、B 两台机器同时拍。剪出来是两个镜头，但分镜期常画成一张带机位标注的图。
3. **AI 生成的分段**：单个镜头可能生成多张候选图，或按单段时长上限拆成多段视频再拼接。这是技术实现的分段，最终仍是一个镜头。

### 剧集 ≠ 集

这两个词日常混着说，但在制作层级上是两层：

- **剧集 (series)** = 整部剧，包含多集。
- **集 (episode)** = 第几集，一集包含多场。

所以准确的说法是「剧集 → 多集 → 每集多场 → 每场多镜头」，中间不能省掉「集」。

### 场 ≠ 场景

| 术语 | 是什么 | 例 |
|---|---|---|
| 场 (scene / 场次) | 剧本的叙事单位：同一时间、同一地点的连续动作 | 3-5 场：会议室，下午 |
| 场景 (set / 地点) | 美术概念：一个可搭建、可复用的物理空间 | 「董事长办公室」这个景 |
| 镜头 (shot) | 制作单位 | 3-5-02 镜 |

同一个场景可以承载几十个场（办公室出现在第 3、7、12 集）；反过来，一场戏通常只发生在一个场景里。所以从制作层级上说，是「**一场多个镜头**」，而不是「一个场景多个分镜」。

### 机位 ≠ 镜头

- **机位 (camera setup)** 是物理概念：机位在哪、多高、朝哪、用什么镜头。
- **镜头 (shot)** 是剪辑概念：一次开机到停机之间连续呈现的一段画面。

一个机位可以拍出多个镜头（同一机位分两条拍，剪成两个镜头），一个镜头也可能靠运动换取多个构图。所以更准确的说法是「**每个分镜条目都要指定这一镜的机位和运镜**」，而不是「镜头里装着机位」。

## 镜头的运用包含什么

分镜表里除了「画面内容」（拍什么），另一半是「怎么拍」，也就是镜头语言：

| 维度 | 选项 | 作用 |
|---|---|---|
| 景别 | 远 / 全 / 中 / 近 / 特写 | 控制信息量与情绪距离 |
| 角度 | 平视 / 俯视 / 仰视 / 越肩 / 过肩 | 控制权力关系与压迫感 |
| 机位 | 位置、高度、距离、朝向 | 决定空间关系与遮挡 |
| 运镜 | 固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 手持 | 控制节奏与主观感 |
| 焦段 | 广角 / 标准 / 长焦 | 控制透视、畸变、压缩感 |
| 景深与焦点 | 深焦 / 浅景深 / 移焦 | 引导注意力 |
| 光线 | 光位、光比、色温 | 定氛围与质感 |
| 时长 | 秒 | 定节奏 |
| 转场 | 切 / 叠化 / 黑场 | 定段落关系 |

一个分镜条目的完整信息可以概括为两部分：

> **内容层**：谁、在哪、做什么、说什么<br>
> **形式层**：景别、角度、机位、运镜、焦段、光线、时长、转场

### 一个填写完整的例子

```text
集 / 场：第 3 集 · 3-5 场（会议室，下午）
镜号：3-5-02
景别：中景 → 近景
角度：平视，略偏侧
机位：桌子右侧 1.5m，机高 1.2m
运镜：缓慢推近
焦段：50mm，浅景深
时长：3.5s
画面：人物把文件推到桌对面，对面的人没有接
台词：（无）
转场：硬切
```

## 容易混的几个概念

- **剧本**：叙事层，按「场」写，不关心机位。
- **场 (scene)**：同一时间、同一地点的连续动作，一场可含多个镜头。
- **镜头 (shot)**：摄影机一次开机到停机，是制作的最小单位，也就是分镜表的一行。
- **分镜**：把「场」拆成「镜头」的结果，既指工序，也指表格和图示。
- **动态分镜 / animatic**：分镜的下一步，按时间轴预演。
- **剪辑**：成片阶段，按分镜与实拍素材重新组织节奏。

一句话记：**场是叙事单位，镜头是制作单位，分镜是镜头的书面化形式。**

## 景别与运镜小抄

| 景别 | 取景范围 | 常见用途 |
|---|---|---|
| 大远景 / 远景 | 环境为主，人很小 | 交代地点、时间、规模 |
| 全景 | 人物全身，头顶到脚底 | 交代人物与环境关系 |
| 中景 | 膝盖或腰部以上 | 对话、动作 |
| 近景 | 胸部以上 | 表情、情绪 |
| 特写 | 面部或局部 | 强调、转折 |
| 大特写 | 眼睛、手指等细节 | 强刺激、悬念 |

| 运镜 | 含义 |
|---|---|
| 固定 | 机位不动 |
| 推 / 拉 | 镜头向主体靠近 / 远离 |
| 摇 | 机位不动，机身水平或垂直转动 |
| 移 | 机位本身平移 |
| 跟 | 跟随主体运动 |
| 升降 | 机位上下移动 |
| 手持 | 模拟人眼的不稳定感，强调临场与紧张 |

## 在 AI 短剧流水线里的位置

把上面的概念套到 AI 生成流程里，层级依然成立：

```text
剧本 → 剧集级资产（人物设定、场景空镜） → 分镜（逐镜头关键帧） → 图生视频 → 配音/字幕 → 剪辑成片
```

对应的数据关系可以这样理解：

- **剧集级**：人物三视图、场景空镜这类可复用的美术资产，一次生成、多镜头复用。
- **分镜级**：每个镜头一条记录，包含画面提示词、摄像机与景别描述、时长、对白，以及关键帧和视频的生成结果。
- **同一镜头的多张候选图 / 多段视频**：属于生成环节的分段与择优，不改变「一个镜头」的计数方式。

这也是为什么分镜表在 AI 制作里仍然重要：模型只负责画，**镜头怎么拆、每个镜头承担什么叙事任务，仍然是人来定的**。

## 一句话总结

场是叙事单位，镜头是制作单位，分镜是镜头的书面化形式；一个镜头对应一个分镜，不要反过来理解。

完整的链条再记一遍：

```text
剧本 → 剧集 → 集 → 场 → 镜头(＝一个分镜) → 帧
```

其中「场景」是美术资产、「机位」是物理设置，它们都不是叙事层级里的格子；分镜条目要做的，是把这一镜的机位和运镜写清楚。
